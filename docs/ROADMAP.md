# PiOS NOVA Roadmap

## 0.1 — Web alpha
- Authenticated desktop, windows, dock, private notes, scoped file uploads, system monitor
- Add automated tests, login rate limiting, CSRF/proxy review, backup and audit trail before wider release

## 0.2 — Hybrid
- Optional Wayland / Chromium local HDMI kiosk
- Separate session state for local and remote clients

## 0.3 — App Engine
- Versioned manifests, capabilities, scoped API tokens, sandboxed origins
- Isolated backend processes, resource quotas and install/update/uninstall

## 0.4 — Developer
- SDK, code editor, app templates, testing harness

## 1.0 — Release
- Reproducible installer, upgrades, backup/restore, accessibility, CI and threat model

No public access or untrusted third-party app execution in alpha.
